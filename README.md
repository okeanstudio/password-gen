# password-gen

Мини-утилита на C++17 для генерации паролей с оценкой энтропии и проверкой на слабые паттерны.

## Возможности
- Генерация паролей заданной длины.
- Выбор наборов символов: строчные, заглавные, цифры, спецсимволы.
- Исключение неоднозначных символов (`l`, `1`, `I`, `O`, `0`).
- Оценка энтропии пароля в битах.
- Проверка на слабые паттерны (повторы символов, простые последовательности).

## Сборка

Для сборки требуется CMake (версия 3.16 или выше) и компилятор с поддержкой C++17.
